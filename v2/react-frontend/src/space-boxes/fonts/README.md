These are the existing scene's Outfit and IBM Plex Mono font families, served
locally to keep the Pages release independent of the Google Fonts service.

Downloaded 2026-10-18 from the Google Fonts repository:

- [Outfit variable font](https://github.com/google/fonts/tree/main/ofl/outfit)
- [IBM Plex Mono Light and Regular](https://github.com/google/fonts/tree/main/ofl/ibmplexmono)

The original SIL Open Font License files are included alongside the fonts.
