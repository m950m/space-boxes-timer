Character artwork preview

Owner evaluation only — this character system is a proposal, not approved artwork. The production page (v2/frontend/index.html) and its dormant artwork hooks are unchanged. Every asset is original static SVG created for this preview.

The five session states

One character: a warm gold head whose open crown holds a physical kraft box. The same geometry is shared by every state, so swapping assets never shifts layout. Each state is identifiable by shape alone — closed box, open slots, released cube, half-closed lid, taped check — never by color alone.

Zero to three Primary tasks

The planning composition carries the approved zero-to-three Primary rule: occupied slots show numbered cubes (1–3, matching card order); unused slots stay visible as outlines. No fourth box is ever created.

In the interface

A replica of the two prepared integration sites, using the same host classes (task-artwork) and the documented mounting recipe: clone the inert template, set src, intrinsic size and empty alt before inserting, then replaceChildren(). Hosts stay aria-hidden; images never intercept pointers; task text stays in real text nodes.

Design notes

Flat shapes, one outline weight, no gradients and no animation: crisp at every size, safe under forced colors, and identical under reduced motion. The palette is anchored to the existing planner interface.

head gold #f4bc55 shade #e0a238 outline = --ink #182c3d box kraft #e3b271 task 1 #3e7cb8 task 2 #e8823c task 3 #c9b37e focus orbit #9ec1dd complete check #2f7d46

Deliberate differences from the reference illustration: front-facing rounded head with ears (reads at small sizes better than a profile), the box nested inside a cut crown rim, and no galaxy stream — the space connection is one orbit ring in FOCUS only, so decoration never competes with tasks. Assets are generated by assets/artwork/generate.py for provenance and consistent iteration.

Decisions needed from the owner

  1. Approve or reject this character direction (head/box metaphor, palette, expression style).
  2. Approve the five state treatments, or mark per-state changes (e.g., FOCUS ring density, PAUSE bars).
  3. Confirm slot numbering 1–3 tied to card order is the desired task association.
  4. Decide the Extra/subtask badge concept (targeted cube) or request an alternative.
  5. Decide whether COMPLETE artwork should appear after any ended session or only completed ones.
  6. After approval: pick integration scope (planner host only vs. both hosts) and authorize the production integration task.

Nothing here replaces the acceptance requirements in ARTWORK-INTEGRATION.md; approval of this preview would start the recorded asset/provenance handoff, not automatic integration.
